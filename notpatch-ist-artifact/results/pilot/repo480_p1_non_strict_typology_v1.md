## Interpretation

- Set A: no non-strict P1 row is explained by misread task-time evidence (0/23). Most rows (16/23) involve observably different behaviors that the packet left open and the hidden test fixed. Where the P1 record had named that choice as its bounded assumption (10 rows), the hidden test selected within a residual the codebook admits in P1, which supports the reading that oracle selection also operates inside P1. The remaining 6 contract-choice rows are boundary-displacement candidates.
- The independent panel labeled 3 of the 11 contract-choice rows it covered as P2/P3, so a second panel mostly did not recognize the competing behavior at task time either.
- Set B: 12/22 disagreements concern whether an alternative both outcomes acknowledge is a separate target, the same gray zone as the anticipated Set A rows. Evidence-use differences explain 4 rows and occur in both outcomes.
- Codebook clarification candidate (new version only): treat a residual choice that changes a tested observable (return value, success versus exception, default output, emitted text) as a separate target unless packet evidence selects one, and record such alternatives explicitly in P1 records.
